# Checklist contra la rúbrica
Estados: ✅ completado y verificado · 🟡 preparado, pendiente de acción externa · ⏳ pendiente de evidencia o información

| Criterio (peso) | Estado | Detalle / qué falta |
|---|---|---|
| Proceso UX (20) | 🟡 | Hay reseñas de revisión entre pares y cambios aplicados. Falta: completar benchmark (2 portfolios), test con tareas medidas.
| Diseño visual y design system (20) | 🟡 | SVG de moodboard, design system y prototipos listos. Falta: importarlos a Figma, crear componentes, armar prototipo y link. |
| Estructura de información (10) | ✅ | 9 secciones presentes. Falta reemplazar textos [COMPLETAR] y datos de contacto. |
| Maquetación HTML/CSS (20) | ✅ | Semántico, 1 h1, sin scroll horizontal a 375/768/1280 px (probado con Chromium). Falta revisar fidelidad con tu Figma final. |
| Accesibilidad y performance (10) | ✅ local / 🟡 público | Lighthouse mobile en servidor local: 98/100/100/100. Repetir sobre la URL publicada y guardar captura. Teclado: primer foco en “Saltar al contenido”. |
| Despliegue y repositorio (20) | 🟡 | Workflow de GitHub Pages y README listos. Falta: crear repo, ≥10 commits reales, URL pública, completar README. |
| Bonus | ⏳ | Dominio propio, modo oscuro, formulario: no incluidos. |

URL de Figma, URL pública, imágenes reales de proyectos (las actuales son ilustraciones).
